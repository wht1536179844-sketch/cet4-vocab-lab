# 四级真题划词背词工坊 (CET-4 Vocab Lab)

还原「从四级真题中直接划词背单词 + 备考速刷 + 2:1 复习新学 + 错词本」工作流。

## 功能亮点
- **2025–2026 年共 9 套四级真题**（默认从 **2026年6月 第1套** 开始，涵盖 2026年6月 第1/2/3套、2025年12月 第1/2/3套、2025年6月 第1/2/3套）。
- **真题划词精读**：单击任意单词即弹出音标、中英释义、真题搭配与外放发音，一键荧光标黄并收入「本卷自制生词本」；拖选词组或整句支持逐词拆解与存为词组。
- **备考速刷 & 2:1 模式**：复刻「快速、大量、多轮、不卡词」速刷机制，支持「认识直接过 / 不会入错词本」，并支持 2:1（2倍复习:1倍新学）每日推送与四级真题核心词/大纲词练习。
- **自制词本 & 错词管理**：支持「昨日新增生词·今日必刷」筛选、TXT 导出与 JSON 备份恢复。

## 本地开发
```bash
npm install
npm run dev
```
